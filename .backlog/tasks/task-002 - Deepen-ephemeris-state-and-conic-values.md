## Description

<!-- SECTION:DESCRIPTION:BEGIN -->

> _This was generated by AI during triage._

From architecture review: the ephemeris interface exposes raw SPICE argument ordering and positional list shapes.

Problem: Callers must know SPICE names/codes, argument order, six-element state vectors, and eight-element conic element positions. The module interface is nearly as complex as the native implementation, so shape mistakes would spread across callers and tests.

Intent: Move state vector and conic element shape into the ephemeris module. Keep raw lists and native conversion behind the NIF adapter while preserving access to SPICE behavior.

Recommendation strength: Worth exploring.
