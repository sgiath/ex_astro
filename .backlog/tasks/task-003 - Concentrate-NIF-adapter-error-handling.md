Problem: Error behavior and adapter contract knowledge are scattered across time.c, ephemeris.c, support.c, utils.h, and Elixir NIF stubs. Adding a native function requires manually keeping multiple seams consistent, and tests mostly exercise final behavior rather than the adapter contract.
